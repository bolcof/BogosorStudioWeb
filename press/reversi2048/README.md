# Reversi2048 プレスキット

編集元: content.json（日英）。Steamデモ版（AppID 4813900）の原文を使用。取得記録: sources/steam-demo-copy-ja.json と steam-demo-copy-en.json。
生成: `python3 press/reversi2048/build.py`（サイトルートから実行）。
出力: docs/presskits/Reversi2048/。ゲーム紹介ページは上書きしません。
作品ページのボタンは content/games/Reversi2048.md および他5言語のMarkdownで管理し、既存の scripts/apply_games_csv.rb で生成します。

スクショは出力先の assets/ へ追加し、content.json の screenshots に file と caption（ja/en）を登録して再生成します。
例: {"file":"Reversi2048-Screenshot01.png","caption":{"ja":"対局画面","en":"Gameplay"}}
ZIPにも同時に収録されます。
メール下書きのプレスキットURLはWeb公開後に記入してください。

## 動画

media/Reversi2048-Title.mp4 は提供された TItle.mp4 の無加工コピー。GIFは全編・960×540・15fps・無限ループで変換。公開ファイルは docs/presskits/Reversi2048/media/。ページ内再生・個別ダウンロードに対応し、素材ZIPには含めません。出典とハッシュは sources/title-video.json。
